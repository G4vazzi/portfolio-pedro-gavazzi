Dashboard Financeiro

Estruturação e análise de dados financeiros utilizando Excel, Power Query e Power Pivot para acompanhamento de operações e indicadores.

Dashboard Financeiro

Sobre o projeto

Este projeto foi desenvolvido para organizar e analisar informações relacionadas a operações financeiras, contratos, parcelas, movimentações e receitas.

A estrutura foi pensada para transformar dados operacionais em informações que possam auxiliar no acompanhamento da carteira e na análise dos resultados financeiros.

Objetivo

Centralizar informações financeiras e facilitar o acompanhamento das operações, permitindo visualizar indicadores e resultados de forma estruturada.

Desenvolvimento

Os dados são organizados no Excel e tratados utilizando Power Query, enquanto o Power Pivot é utilizado para estruturar o modelo e os indicadores necessários para análise.

Estrutura dos dados

O projeto trabalha com diferentes conjuntos de informações financeiras, permitindo relacionar operações, parcelas, clientes e movimentações.

  • Cadastro de clientes
  • Contratos
  • Parcelas
  • Movimentações financeiras
  • Receitas das operações
  • Status das operações

Tratamento dos dados

O Power Query é utilizado para organizar, transformar e preparar os dados antes da análise.

Essa etapa permite padronizar informações, estruturar tabelas e preparar os dados para utilização no modelo analítico.

Indicadores

  • Receita das operações
  • Lucro das operações
  • Carteira ativa
  • Contratos ativos
  • Parcelas em atraso
  • Valores recebidos
  • Movimentações financeiras
  • Evolução dos resultados

Tecnologias utilizadas

Microsoft Excel Power Query Power Pivot Modelagem de Dados Análise de Dados

O que este projeto demonstra

Este projeto demonstra minha capacidade de trabalhar com dados financeiros, desde a organização das informações até sua transformação em indicadores para análise.

Também demonstra conhecimentos em tratamento de dados, modelagem, criação de indicadores e utilização de ferramentas do ecossistema Microsoft para análise de informações.
