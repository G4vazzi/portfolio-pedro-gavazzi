SpacoContabil

Sobre o projeto

O SpacoContabil é um projeto de desenvolvimento web criado para apresentar os serviços de uma empresa contábil de forma profissional, organizada e acessível.

Além das páginas institucionais, o projeto também conta com ferramentas interativas desenvolvidas para auxiliar usuários em diferentes situações relacionadas a negócios e finanças.

Objetivo

Criar uma presença digital profissional para uma empresa contábil, organizando informações sobre seus serviços e disponibilizando ferramentas úteis aos usuários.

Desenvolvimento

O projeto utiliza HTML, CSS e JavaScript para construção das páginas e implementação das interações, com estrutura organizada para facilitar a manutenção e evolução do sistema.

Funcionalidades

  • Página institucional
  • Apresentação de serviços
  • Página "Quem Somos"
  • Página de contato
  • Menu de navegação
  • Menu de ferramentas
  • Calculadoras interativas
  • Layout responsivo

Ferramentas desenvolvidas

Uma das características do projeto é a criação de ferramentas interativas para transformar cálculos e informações técnicas em uma experiência mais simples para o usuário.

  • Calculadora de abertura de empresa
  • Calculadora PJ x CLT
  • Simuladores financeiros
  • Ferramentas para tomada de decisão

Tecnologias utilizadas

HTML CSS JavaScript Python Flask Git GitHub

O que este projeto demonstra

O projeto demonstra minha capacidade de desenvolver interfaces web completas, trabalhando com estrutura de páginas, estilização, navegação e interações utilizando JavaScript.

Também demonstra minha preocupação em transformar necessidades reais de negócio em ferramentas digitais simples e acessíveis para o usuário.
